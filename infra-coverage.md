## Agreed source contracts

- Native checkpoint operations live in `_backend.common.checkpointing`, not conversion utilities.
- `load_state_if_possible` returns the original `(full_state, params)` pair and restores into the original data iterator.
- Standard checkpointing uses Orbax v1. Emergency and replicator managers retain their separate v0 protocol.
- HF stream adaptation does not imply exact source-cursor checkpoint restoration.
- Offline HF distillation selects pretokenized `inputs`, `top_k_logits` and `top_k_indices`, reshapes the top-k fields by sequence length, and skips SFT formatting and tokenization. Iterable datasets use one thread and no Grain workers. The tokenizer is still loaded, and a missing pad ID becomes zero.
- Distillation dataset generation accepts conversational `messages` or `prompt`/`completion` columns and filters using the first prompt and completion. Its dataset loader supports Hugging Face datasets only.
- Grain mmap and mmap_npy reject elastic iterators in both source and target; authored paths are not runtime verification.
- Automatic CPU projection reloads model defaults and transfers model name, scan setting, checkpoint storage settings and an explicitly supplied HF token; it forces `use_multimodal=False`. Explicit public conversion preserves the full configuration with CPU, output-directory and distributed-initialization overrides, including the effective scan setting; lazy multimodal conversion remains rejected.
- Native on-the-fly conversion passes the native configuration to the CPU worker, overriding the output directory, multimodal setting and distributed initialization. It requires an HF token when conversion is needed. Process zero runs the worker and broadcasts the result. Explicit native conversion preserves the multimodal setting.
- PaxML's direct default entry point loads base and model configuration with batch size 1, FSDP -1, tensor parallelism 1, checkpoint period 1 and asynchronous checkpointing disabled. The converter requires a `gs://` source.
- Native HF import saves step zero under `base_output_directory`, or `tmp/{run_name}` when empty. Adapter-only conversion appends model and adapter names. It does not use the training checkpoint directory automatically.
- Registry identity remains distinct across `HF_IDS`, `HF_MODEL_CONFIGS`, `PARAM_MAPPING`, `HOOK_FNS`, and export shape mappings.
- Original `common/gcloud_stub.py` supplies optional-dependency and no-op stubs; these are intentionally not migrated under the no-stubs/no-fallback instruction. Real service integrations are separate and unverified.
