## Frozen cross-owner handoffs

- Public model wrapper retains the exact `native_model` and `runtime` objects. Training injects that native model without recreation.
- Initialized `Runtime.config` must be migrated native `HyperParameters`; `Runtime.mesh` owns the mesh. The inert public configuration is not a substitute.
- Foundation owns `_backend/configs/`, including `resolve_runtime_config(public_config)`, and all public configuration/runtime modules.
- Native checkpoint functions belong to `_backend.common.checkpointing`. Conversion entry points belong to `_backend.checkpoint_conversion` and must consume resolved native configuration without argv normalization.
- HF conversion saves native checkpoint step zero under the converter's actual output root. The authored import return follows the original consumer's `output_root/0/items` path; provider interoperability and runtime behavior remain unverified.
