# Declared logical-axis rule defaults

This is the declared default for `sharding.logical_axis_rules` in an [execution profile](execution-profile-placement.md#sharding). Model preparation can merge model-specific rules, and mesh presets can replace them. Omission in a profile preserves those prepared rules. It does not insert this list as an override.

Each pair maps a logical tensor dimension to physical mesh dimensions. Empty targets replicate the dimension. Repeated names retain their ordered alternatives.

The built-in ordered rules are listed below.

<summary>Parameters</summary>

- `logical_axis_rules` (`list | tuple`, optional, defaults to the built-in rules above). Ordered logical-axis and mesh-axis pairs. Targets are an axis-name string or a sequence of axis names. Empty targets replicate the dimension.
